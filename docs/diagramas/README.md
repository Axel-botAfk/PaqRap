# diagramas

Diagramas del proyecto. Cada página describe lo que está implementado en el código, con la clase
o el archivo real al lado de cada elemento, no la arquitectura propuesta en los documentos de
diseño. Si se sube una imagen exportada, acompañarla de su archivo fuente editable.

| Archivo | Qué explica | Ítem de la evaluación |
| --- | --- | --- |
| `planificador-visualizador.md` | Cómo interactúan el Visualizador, la API, el motor y el planificador, y qué pasa cuando el canal en vivo se corta o se cancela la corrida | Semana 8 |
| `consumo-sc-sa.md` | Cómo se consumen los datos en bloques de tiempo Sc por cada bloque Sa del planificador, con los valores de cada escenario | A22 |
| `varios-navegadores.md` | Cómo interactúan varios navegadores sobre la misma corrida: qué es independiente, qué es compartido y qué pasa si a uno se le cae el canal | A23 |
