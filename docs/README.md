## Convención de nombres

`NN.dis.nombre.vX.Y.docx`, por ejemplo `25.dis.gui.v1.1.docx`. Al subir una versión nueva, se sube el archivo con la versión actualizada en el nombre; no se pisa la anterior sin motivo.

## Diagramas

Los diagramas (por ejemplo, la interacción Planificador–Visualizador de la semana 8) van en `docs/diagramas/`, con su fuente editable si existe.
